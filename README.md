# Калькулятор прогрессивного НДФЛ РФ

GUI-приложение для расчета прогрессивного налога на доходы физических лиц (НДФЛ) в России с 2025 года.

## Возможности

- **Расчет gross → netto**: Ввод зарплаты до налогов, расчет чистой зарплаты
- **Расчет netto → gross**: Ввод чистой зарплаты, расчет зарплаты до налогов
- **Месячные доходы**: Поддержка ввода 12 месячных доходов
- **Прогрессивная шкала**: Автоматический расчет по ступеням налогообложения
- **Адаптивный интерфейс**: Возможность изменения размера окна
- **Экспорт результатов**: Сохранение в TXT, CSV, JSON, Excel форматах
- **История расчетов**: Автоматическое сохранение последних 50 расчетов
- **Визуализация данных**: Графики кумулятивного дохода/налога и месячной зарплаты
- **Горячие клавиши**: Быстрые действия с клавиатуры
- **Улучшенная валидация**: Проверка корректности ввода данных

## Налоговые ставки (с 2025 года)

- **13%** - до 2,4 млн рублей
- **15%** - от 2,4 до 5 млн рублей
- **18%** - от 5 до 20 млн рублей
- **20%** - от 20 до 50 млн рублей
- **22%** - свыше 50 млн рублей

## Установка зависимостей

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

### Из исходного кода

```bash
source .venv/bin/activate
python main.py
```

### Создание EXE файла

Для создания автономного .exe файла запустите:

```bash
build.bat
```

Готовый файл будет в папке `dist/NDFL_Calculator.exe`

**Документация по сборке:**

- [build_tools/README.md](build_tools/README.md) - Быстрый старт и обзор
- [build_tools/BUILD_INSTRUCTIONS.md](build_tools/BUILD_INSTRUCTIONS.md) - Полная инструкция

## Горячие клавиши

- **Ctrl+Enter** или **F5** - Выполнить расчет
- **Ctrl+S** - Экспорт в TXT
- **Ctrl+H** - Показать историю

## Требования

- Python 3.8+
- tkinter (входит в стандартную библиотеку Python)
- openpyxl (для экспорта в Excel)
- matplotlib (для визуализации графиков)
