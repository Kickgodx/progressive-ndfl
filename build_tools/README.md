# Инструменты сборки EXE

Эта папка содержит все необходимое для создания исполняемого файла приложения.

## 🚀 Быстрый старт

**Из корня проекта:**

```bash
build.bat
```

**Из этой папки:**

```bash
cd build_tools
build.bat
```

**Результат:** `dist/NDFL_Calculator.exe` (~50-80 МБ)

---

## 📁 Файлы

| Файл                    | Назначение                  |

## 🔧 Требования

- Python 3.8+
- PyInstaller 6.0+
- Все зависимости из `requirements.txt`

Установка:

```bash
pip install -r requirements.txt
```
